A practical guide to the Causal Roadmap, Targeted Maximum Likelihood Estimation (TMLE), and Super Learner for modern causal inference in epidemiology, with emphasis on pharmacoepidemiology and clinical trial analysis.

Author

Andrew Mertens

Welcome!

This handbook introduces the Causal Roadmap, Targeted Maximum Likelihood Estimation (TMLE), and Super Learner for modern causal inference in epidemiology, with an emphasis on pharmacoepidemiology and clinical trial analysis. Each chapter builds on the previous ones, with worked R code examples throughout.

0.1 Who is this book for?

This handbook is written for analysts who already know how to fit regression models in R and now need to do causal analysis on observational health data, primarily pharmacoepidemiologists, biostatisticians, and epidemiologists working on drug effectiveness, safety, and real-world evidence. The worked examples assume comfort with R and basic regression; they do not assume prior exposure to potential-outcomes notation, targeted learning, or g-methods.

The book is not a substitute for a foundational causal inference text (for that, and other useful references, see the Other Resources page), but it is intended to be self-contained for someone working through a longitudinal real-world-data analysis from scratch. A Glossary is provided in the appendix for the abbreviations and short technical terms used throughout.

0.2 How to use this book

Short on time? Start with the Short Course. It covers the Causal Roadmap, TMLE (by hand and with software), and longitudinal causal inference in a single chapter. You can work through it in about an hour and come away with a working understanding of the core framework.

Want the full treatment? Read the handbook front-to-back. The chapters are organized into six parts. Part I builds the conceptual foundations: why standard regression is not enough for causal questions, and how the Causal Roadmap structures an analysis. Part II walks through each major estimation strategy with hands-on code. Part III extends to longitudinal settings with time-varying confounding, longitudinal TMLE (L-TMLE), and Longitudinal Modified Treatment Policies (LMTP). Part IV covers diagnostics and sensitivity analysis. Part V is an end-to-end applied workflow built around the lmtp package. Part VI addresses special topics including effect heterogeneity, mediation, hybrid RCT/RWD designs, and time-to-event estimands. A short Synthesis part then revisits the running case study, and the appendices collect a glossary, an annotated bibliography, and external resources.

You can also jump to specific chapters as needed. Each chapter is self-contained enough to be read independently, though they build on each other.

0.6 Part II: Core Estimators

Chapter Description
G-Computation Outcome modeling and standardization: fit a model for the outcome, predict each person’s outcome under each treatment value, and average across the sample.
IPTW Inverse-probability-of-treatment weighting: weight each individual by the inverse of their probability of receiving the treatment they actually got, so the weighted sample mimics one in which treatment was randomized. Covers stabilized weights, truncation, and diagnostics.
Doubly Robust Estimation and TMLE Augmented Inverse Probability Weighting (AIPW) and Targeted Maximum Likelihood Estimation (TMLE): combining outcome and treatment models for double robustness.
Super Learner Ensemble machine learning for nuisance estimation and integration with TMLE.

installed <- rownames(installed.packages())
to_install <- setdiff(all_pkgs, installed)
if (length(to_install) > 0) {
  install.packages(to_install, dependencies = TRUE)
}
